================================================================================
FILE NAMING PATTERNS FOR YOUR SCRAPER
================================================================================

PATTERN 1: Original Base Files
  Format: {DATASET_NAME}.csv
  Examples:
    - NBA_IL.csv
    - NBA_Missed_Games.csv
  
  → Use these once when initializing your app
  → Combine and save as: NBA_IL_combined.csv, NBA_Missed_Games_combined.csv


PATTERN 2: Initial Update Files (Feb 2026)
  Format: {DATASET_NAME}_Updated__{DATE}_-_Sheet1.csv
  Examples:
    - IL_Updated__02-27-26_-_Sheet1.csv
    - Missed_Games_due_to_Injury_Updated__02-27-26_-_Sheet1.csv
  
  → Transition format - only used once


PATTERN 3: Standardized Incremental Updates (Mar 2026+)
  Format: {DATASET_NAME}__[START_DATE]__[END_DATE].csv
  Examples:
    - IL_Transactions__02-25-2026__03-19-2026.csv
    - Missed_Games_Due_to_Injury__02-25-2026__03-19-2026.csv
  
  → This is the pattern your scraper should produce
  → [START_DATE] = day after previous update ends
  → [END_DATE] = current date
  → Append to combined files (don't replace)


3. Create a daily scraper that:
   - Scrapes new IL + Missed Games data (since last update date)
   - Names files: IL_Transactions__[LAST]__[TODAY].csv
   - Appends to combined files
   - Runs: python process_injuries_pipeline.py
   - Outputs: nba_injuries_merged.csv
   - Updates private app database

4. Run process_injuries_pipeline.py:
   ```bash
   python process_injuries_pipeline.py \
       NBA_IL_combined.csv \
       NBA_Missed_Games_combined.csv \
       nba_injuries_merged.csv
   ```

5. Quality checks built into script:
   - Validates duplicates removed
   - Ensures all classified
   - Checks date ranges
   - Outputs summary statistics

================================================================================
LEGAL NOTES FOR YOUR PRIVATE APP
================================================================================

✓ SAFE TO SCRAPE:
  - Injury reports (factual information)
  - Official IL placements (public data)
  - Player names and teams (public domain)
  - Dates and body parts (factual)

✗ DON'T SCRAPE:
  - Game statistics (copyrighted)
  - Video highlights (copyrighted)
  - News articles verbatim (copyrighted)
  - Licensed performance metrics

⚠️ BEST PRACTICES:
  - Check site's robots.txt and Terms of Service
  - Rate limit requests (1+ second between requests)
  - Identify your scraper with User-Agent
  - Cache aggressively (don't hit servers constantly)
  - Respect copyright - only factual data
  - Keep app private (don't distribute publicly)
